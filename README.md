# lampac-aniskip

Метки заставки, титров и рекапа из [AniSkip](https://api.aniskip.com) для любого онлайн-провайдера [lampac-nextgen](https://github.com/lampac-nextgen/lampac). Ответ в формате `SegmentTpl` (`{"ad":[],"skip":[{"start","end"}]}`), его уже понимает Lampa у Kodik, Aladin и Alloha.

## HTTP

| Маршрут | Параметры | Описание |
|---------|-----------|----------|
| `GET /aniskip` | `title`, `year`, `e` (номер серии) | MAL ID берётся через поиск Shikimori (`shikimori.io`, id Shikimori == MAL id). |
| `GET /aniskip` | `mal_id`, `e` | То же без поиска, для отладки. |

Ответ `{}` значит «меток нет» (кэш 12 часов). Сбой сети даёт `503` и не кэшируется. Настроек в `init.conf` нет.

## Установка

Сервер: запись в `module/repository.yaml` (модуль скачается при старте lampac):

```yaml
- repository: https://github.com/smersh16/lampac-aniskip
  branch: main
  modules:
    - AniSkip
  token: env:GITHUB_PAT
```

Клиент: `client/online-plugin.patch` добавляет в `Online/plugin.js` метод `loadSegments`: перед воспроизведением он запрашивает метки, если карточка аниме (жанр «Анимация» и страна производства `origin_country` из JP, CN, KR) и у провайдера нет своих меток. Для сезона 2 и выше год берётся из `air_date` этого сезона в карточке (`object.movie.seasons`): сервер выбирает отдельную запись Shikimori по году выхода.

## Ограничения

- Сезоны выбираются по году выхода: два сезона одного года не различаются; если сезон TMDB разбит на два кура с продолжением нумерации серий, метки встанут не на ту серию.
- Если в карточке нет `seasons` с `air_date`, для сезона 2+ запрос не отправляется.
- Если в карточке нет `origin_country` или страны нет в списке (`['JP', 'CN', 'KR']` в `loadSegments`), запрос не отправляется.
- Метки приходят от разных рипов (`episodeLength=0`), возможен сдвиг на секунды.
- Метки остальных серий плейлиста подгружаются в фоне после старта (по одной); если переключить серию раньше ответа, для неё меток не будет.
- Поиск по названию нечёткий; при неверном совпадении отладьте через `mal_id`.
- Код не собирался в CI, проверка сборки только на сервере.
