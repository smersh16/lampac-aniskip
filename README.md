# lampac-aniskip

Метки заставки, титров и рекапа для любого онлайн-провайдера [lampac-nextgen](https://github.com/lampac-nextgen/lampac). Источники:

- **аниме**: [AniSkip](https://api.aniskip.com), поиск записи по названию через Shikimori;
- **любой сериал TMDB**: [TheIntroDB](https://theintrodb.org) по `tmdb_id`, сезону и серии; для аниме это запасной источник, если AniSkip пуст.

Ответ в формате `SegmentTpl` (`{"ad":[],"skip":[{"start","end"}]}`), его уже понимает Lampa у Kodik, Aladin и Alloha.

## HTTP

| Маршрут | Параметры | Описание |
|---------|-----------|----------|
| `GET /aniskip` | `title`, `year`, `e` | Аниме: MAL ID берётся через поиск Shikimori (`shikimori.io`, id Shikimori == MAL id). |
| `GET /aniskip` | `mal_id`, `e` | То же без поиска, для отладки. |
| `GET /aniskip` | `tmdb_id`, `s`, `e` | Сериал: метки TheIntroDB. Можно добавить `title`/`year`: тогда сначала AniSkip. |

Ответ `{}` значит «меток нет» (кэш 12 часов). Сбой источника даёт `503` и не кэшируется. Настроек в `init.conf` нет.

## Установка

Сервер: запись в `module/repository.yaml` (модуль скачается при старте lampac):

```yaml
- repository: https://github.com/smersh16/lampac-aniskip
  branch: main
  modules:
    - AniSkip
  token: env:GITHUB_PAT
```

Клиент: `client/online-plugin.patch` добавляет в `Online/plugin.js` метод `loadSegments`: перед воспроизведением он запрашивает метки, если у провайдера нет своих. Условия:

- есть сезон и номер серии;
- аниме: жанр «Анимация» и `origin_country` из JP, CN, KR (список в `loadSegments`): запрос с названием и годом (для сезона 2+ год берётся из `air_date` сезона в `object.movie.seasons`);
- любой сериал: источник карточки TMDB (или есть `tmdb_id`): запрос с `tmdb_id`.

Метки остальных серий плейлиста подгружаются в фоне после старта (по одной).

## Ограничения

- AniSkip: сезоны выбираются по году выхода (два сезона одного года не различаются; сезон TMDB из двух куров с продолжением нумерации ставит метки не на ту серию). Метки приходят от разных рипов (`episodeLength=0`), возможен сдвиг на секунды.
- TheIntroDB: покрытие неполное, метки зависят от пользовательских отправок. Лимиты по заголовкам ответа: 30 запросов за окно 10 с и 5000 в сутки.
- Титры «до конца серии» (`end_ms = null`) отдаются как конец в 86400 с; как плеер Lampa пропускает за пределы длины, проверено не было.
- Поиск аниме по названию нечёткий; при неверном совпадении отладьте через `mal_id`.
- Фильмы не поддерживаются (нужны сезон и серия).
- Если в карточке нет `seasons` с `air_date`, для аниме сезона 2+ запрос Shikimori/AniSkip не отправляется (запрос в TheIntroDB остаётся, если есть `tmdb_id`).
- Нет настроек в `init.conf`.
